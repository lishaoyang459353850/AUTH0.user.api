📖 开发文档：如何调用 auth-api.js

本页面通过 auth-api.js 暴露全局对象 window.AuthAPI，供非模块化场景直接调用。

1. 引入方式（在 HTML 中）

<script src="https://cdn.jsdelivr.net/npm/@auth0/auth0-spa-js@2.1.3/dist/auth0-spa-js.production.js"></script>
<script type="module" src="./auth-api.js"></script>

2. API 列表

AuthAPI.login()            // 发起 Auth0 登录（跳转授权页）
AuthAPI.logout()           // 登出并回到首页
AuthAPI.isAuthenticated()  // 返回 Promise<boolean>
AuthAPI.currentUser()      // 返回 Promise<user | null>
AuthAPI.getToken()         // 返回 Promise<string>（getTokenSilently，自动刷新）
AuthAPI.callAPI(path)      // 调用受保护后端，自动带 Bearer Token

3. 使用示例

// 页面加载完成后调用
window.addEventListener('DOMContentLoaded', async () => {
  if (await AuthAPI.isAuthenticated()) {
    const user = await AuthAPI.currentUser();
    console.log('欢迎', user.name);
    const data = await AuthAPI.callAPI('/api/protected/data');
    console.log('API 返回:', data);
  }
});

4. 配置说明

修改 auth-api.js 顶部的三个常量即可： AUTH0_DOMAIN、AUTH0_CLIENT_ID、API_BASE_URL。 切勿在前端写入 client_secret。

部署域名：githubpages.de5.net · 前端仅含 domain + clientId，Access Token 由 SDK 托管
